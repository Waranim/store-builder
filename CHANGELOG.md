# Changelog

## 2025-04-04
### Added
- **auth-service v0.0.1** — инициализация сервиса аутентификации (JWT, базовые роли).

## 2025-04-08
### Added
- **auth-service v0.0.2** — интеграция со сторонним SMTP-сервером для отправки писем подтверждения.

## 2025-04-16
### Added
- **api-gateway v0.0.1** — первая версия API Gateway; роутинг + валидация JWT.

## 2025-04-17
### Added
- **shop-service v0.0.1** — стартовая версия сервиса магазинов.

## 2025-04-18
### Added
- **catalog-service v0.0.1** — стартовая версия сервиса каталога товаров.

## 2025-04-20
### Added
- **order-service v0.0.1** — стартовая версия сервиса заказов.

## 2025-04-24
### Changed
- **auth-service v0.0.3** — модель пользователя упрощена: теперь у пользователя может быть только одна роль.

## 2025-05-05
### Added
- **media-service v0.0.1** — загрузка/хранение медиа-файлов в MinIO.

## 2025-05-10
### Added
- **catalog-service v0.0.2** — бренды, категории и поиск товаров по ним; загрузка изображений в MinIO.

## 2025-05-15
### Added
- **order-service v0.0.2** — корзина покупателя, кэш Redis и интеграция с catalog-service.

## 2025-05-19
### Added
- **payment-service v0.0.1** — сервис оплаты.

## 2025-05-20
### Added
- **auth-service v0.0.4** — публичный эндпоинт регистрации + создание покупателя в order-service.

## 2025-05-25
### Changed
- **api-gateway v0.0.2** — переработана фильтрация:
    - запросы без токена проходят дальше;
    - при наличии токена выполняется строгая валидация и добавляются заголовки `X-User-Id`, `X-Role`.

## 2025-05-30
### Added
- **notification-service v0.0.1** — сервис уведомлений (Kafka → e-mail).

## 2025-06-02
### Added
- **catalog-service v0.0.3**, **media-service v0.0.2**, **order-service v0.0.3**, **shop-service v0.0.2** — внедрён контроль доступа для ограничения доступа к эндпоинтам по ролям.

### Changed
- **catalog-service v0.0.3** — поиск теперь учитывает и название, и описание товара.
- **order-service v0.0.3** — создание покупателя перенесено в auth-service.
