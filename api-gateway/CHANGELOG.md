## [0.0.2] - 2025-05-25
### Изменено
- Изменена политика фильтрации запросов. 
Ранее любой запрос без токена, кроме сервиса аутентификации, отклонялся. 
Теперь запрос на этапе api gateway отклонялся только при ошибке валидации токена.
Если токен в запросе есть, то заголовки добавляются, иначе запрос идёт дальше.
